# Tessella

**A seamless pattern studio built on real mathematics.** Design a motif, apply
one of six crystallographic symmetry groups — the *wallpaper groups* — and
export a production-ready SVG or PNG that tiles perfectly, forever.

Pure HTML/CSS/JavaScript: no libraries, no build step, everything runs in the
browser.

## What makes it unique

Most "pattern makers" just repeat a tile. Tessella works with the actual
**wallpaper group classification**: every pattern on the plane belongs to one
of 17 symmetry groups, and Tessella exposes six of them — the square-lattice
families — as first-class design tools:

| Group | Symmetry | Copies per tile |
|---|---|---|
| `p1` | translation only | 1 |
| `p2` | 180° rotations | 2 |
| `pm` | one mirror axis | 2 |
| `pmm` | two mirrors + turns | 4 |
| `p4` | 90° rotations (pinwheels) | 4 |
| `p4m` | full square symmetry | 8 |

The preview shades the **fundamental domain** — the smallest region that,
combined with the group's transforms, reconstructs the entire pattern. It's a
pattern tool *and* a gentle lesson in group theory.

## What users can do

- **Generate motifs** procedurally: dots, radial spokes, petals, spirals,
  zigzags, arcs, stars, waves — density-controlled and seed-reproducible
- **Draw their own motif** with the mouse: strokes wrap seamlessly across tile
  edges (Tessella splits crossing strokes automatically)
- **Color** with six curated palettes or a live **color-harmony generator**
  (analogous, complementary, triadic, split, mono)
- **Export vector SVG** — a `<pattern>`-based file that tiles at any size,
  perfect for print, plotter art, and web backgrounds
- **Export PNG** at tile resolution
- **Save designs** locally and hit **Randomize** for instant inspiration

## Run it

> **Try it live:** <https://joshua12312617.github.io/tessella/>

```sh
cd js-tessella
python -m http.server 8000
```

Open <http://localhost:8000> — no install, no sign-up.

Try the included example: [`examples/example-pattern.svg`](examples/example-pattern.svg)
(a `p4m` "Moroccan Star" in the terracotta palette, generated by the same
exporter the app uses).

## Architecture

```text
index.html            the studio shell
style.css             editorial, print-inspired theme (fully responsive)
js/
├── theory.js         pure math, no DOM: symmetry groups, seamless stroke
│                     wrapping, procedural motifs, seeded RNG, color harmony
├── svg-export.js     vector export — builds the <pattern>-based SVG (pure
│                     string generation, unit-tested)
├── tile-engine.js    canvas renderer: tiled preview + fundamental domain
└── app.js            UI state, controls, drawing, export, localStorage
tests/theory.test.js  12 tests with Node's built-in test runner
```

The math is deliberately isolated in `theory.js` so it can be proven correct:
tests assert group orders (1, 2, 2, 4, 4, 8 copies), rotation/reflection
geometry, seamless wrapping of boundary-crossing strokes, motif validity,
color conversions, and the structure of the exported SVG.
